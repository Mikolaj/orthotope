# CLAUDE.md

This directory is worked on from a session rooted in `~/r/horde-ad`, and that repository's `CLAUDE.md` binds here as applicable: its portable-notes section by that section's own terms, and the rest --- the standing checks, the working style, the session facts --- wherever this directory has no rule of its own. Read it in full before touching anything here. What this directory has of its own is `README.md`, the run chapter above all, and the README wins where the two differ.

Two of its rules are restated here, each because a session met it in this directory and did not apply it:

- **The wrong-repo rule in horde-ad's file reads from here in mirror image.** Its build, test and lint commands are the ones that do not transfer; the commands that do are this README's run chapter and `checks.py`, and the shared tools in `~/.claude/bin` take this directory as their argument. *Why:* a session of 2026-09-03 took horde-ad's standing-checks section for the wrong repo's and the run chapter's step 8 subset for the tree's whole check, and the subset is what let a data change in `Main.hs` break 25 audits unseen, found by the next `check-all`.

- **A probe that names one arm runs several: Criterion's positional selector is a prefix.** The roster's names nest, so `classes flip-last-rows/mut-odo-vecdims` runs ten benches under a name that reads as one and `.../mut-odo-vecdims-add-in-leaf-u2` runs four. Read off the legs of 2026-09-09 rather than argued: those two selectors wrote JSONs of ten and four reports, `lib-stage2-lean` two --- itself and its `-u1` --- and `lib-stage1` and `-u2-last` one apiece, their names being nobody's prefix. It fails silently both ways a probe reads a leg: a JSON holding several reports hands whichever ran first to a reader that takes one, and a differenced counter hands back their sum, which is how it was caught --- 56.28 million for `lib-stage2-lean`, being 27.27 plus 29.01, the two arms' own recorded counts. **So check a selector by counting the reports in the JSON it wrote, and never with `--list`**, which prints nothing at all once a positional selector is given, for a prefix these same legs prove selects ten. `-m glob` with a wildcard-free pattern is the exact form horde-ad's portable notes name, and that same count settles it: the legs re-run under it the same evening wrote one report apiece and the right one, `mut-odo-vecdims` included, where the bare form had taken ten. *Why:* those notes carry the prefix rule already but spell their examples as `--benchmark-options=`, a cabal invocation this directory never makes, so the rule reads as being about that harness rather than about the selector; a probe of 2026-09-09 met it, did not recognise it, and quoted three arms' figures that were several arms summed.
